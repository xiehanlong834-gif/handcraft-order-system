# 06 部署与运行说明

## 1. 环境要求
JDK 17+、Maven 3.8+、MySQL 8.0、Python 3.10+（客户端编译另需 Qt 6.x + MinGW，本机已就绪）。

## 2. 一键启动链路（本机实测路径）
```powershell
# ① MySQL(本机无服务方式) —— 数据目录需先 --initialize-insecure 初始化
D:\dev\mysql\bin\mysqld.exe --datadir=D:\dev\mysql-data --basedir=D:\dev\mysql --port=3306

# ② 建库(含种子数据与演示账号)
D:\dev\mysql\bin\mysql.exe -u root --protocol=tcp --default-character-set=utf8mb4 < sql\schema.sql

# ③ 后端
cd java-backend && mvn -DskipTests package
java -jar target\order-backend-0.0.1-SNAPSHOT.jar        # 监听 8080

# ④ 测试(可选)
python scripts\e2e_api_test.py                            # 116/116

# ⑤ 数据分析脚本(可选, 验证与 Java 口径一致)
python python\analytics.py --mysql                        # 直连业务库出报表
python python\test_order_classifier.py                    # 33/33

# ⑥ Qt 客户端(Windows MinGW)
cd qt-app\desktop-demo
qmake handcraft_client.pro && mingw32-make
release\handcraft_client.exe                              # 登录交互
release\handcraft_client.exe creator01 123456             # 命令行自动登录
```

## 3. 账号体系(两套环境)
系统提供两套初始化方式：

- **课程演示环境**：执行 `sql/schema.sql` 后获得演示种子（creator01/admin01/finance01/xiaolin/may，密码 123456；E2E 测试脚本依赖此环境）。
- **真实使用环境**：执行 `sql/reset_for_production.sql`（先按文件内注释把 `<HASH>` 替换为 bcrypt 哈希）→ 清空全部演示/测试数据，仅保留结构 + 入口账号。当前本机即此状态：

## 4. 配置说明
- 数据库账号：java-backend/src/main/resources/application.yml（默认 handcraft/handcraft123）。
- Python 分类脚本路径：同文件 `classifier.script-path`（默认指向仓库 python/）。
- 客户端后端地址：main.cpp 中 `ApiClient::inst()->setBase(...)`（默认 http://127.0.0.1:8080）。
