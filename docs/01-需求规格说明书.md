# 01 需求规格说明书 —— 独立手作创作者订单管理系统

## 1. 引言

### 1.1 编写目的
本文档规定"独立手作创作者订单管理系统"的功能与非功能需求，作为概要设计、详细设计、编码与测试的依据。系统面向独立手作创作者（手工饰品/皮具/烘焙/陶艺/编织等），解决订单散落微信/电话/记事本/Excel、成本利润难核算、库存与订单脱节、进度同步困难等问题。

### 1.2 术语定义
| 术语 | 含义 |
|---|---|
| 创作者 | 手作工作室经营者，系统核心使用者 |
| 订单类型 | CUSTOM定制/READY现货/BATCH批量/GENERAL通用(兜底) |
| 订单状态机 | PENDING_CONFIRM→IN_PRODUCTION→PENDING_SHIPMENT→COMPLETED；CANCELLED/ARCHIVED 分支 |
| 智能分类 | 基于关键词规则自动识别订单类型并计算预估工期 |

## 2. 角色与权限

| 功能域 | 创作者 | 客户 | 管理员 | 财务查看者 |
|---|---|---|---|---|
| 订单管理(建单/进度/取消/归档) | ✔(自己名下) | 仅本人查看/提交定制 | ✖ | ✖ |
| 材料库存(入/出/预警) | ✔ | ✖ | ✖ | ✖ |
| 成本利润(耗料/工时) | ✔ | ✖ | ✖ | 只读报表 |
| 排期日历/工期提醒 | ✔ | 查看预计完成 | ✖ | ✖ |
| 客户管理 | ✔(名下客户) | ✖ | 用户账号管理 | ✖ |
| 经营报表/客户画像 | ✖ | ✖ | ✔ | ✔ |
| 基础数据(产品/材料分类) | 只读 | ✖ | ✔ | ✖ |
| 公告 | 查看 | 查看 | 发布 | 查看 |

> 权限实现：接口层 RBAC 角色校验 + 数据行级隔离（订单按 creator_id / customer_id 过滤）+ 前端按角色渲染导航。

## 3. 功能需求

### FR1 登录认证（P0）
登录（BCrypt 校验、失败提示）、退出、当前用户信息、账号禁用后禁止登录。

### FR1b 公开自助注册（P0）
任意用户可自助注册，仅限"客户"角色：自动创建客户档案并归属系统创作者（单工作室取首个启用创作者）；校验用户名唯一/格式（3-20 位字母数字下划线）、密码 ≥6 位、昵称必填；高权限角色（创作者/管理员/财务）只能由管理员创建，注册接口不开放。

### FR2 订单管理（P0）
创建订单（创作者手动/客户定制提交两种来源）、列表按状态/关键词筛选、详情（含状态审计日志与材料耗用明细）、状态机流转（非法流转拒绝并提示）、取消（软删除保留审计）、归档。

### FR3 智能订单分类与工期提醒（P0，创新点一）
- 关键词规则：含 定制/专属/个性化/按需 → CUSTOM（工期 7 天）；现货/现款/成品 → READY（2 天）；批量/团购/多件 → BATCH（3+ceil(n/5) 天）；未命中 → GENERAL 兜底并提示创作者手动调整。
- 优先级 CUSTOM > READY > BATCH；自动计算预估完成日期。
- 截止前 ≤3 天（含超期未完成）订单进入提醒列表。

### FR4 材料库存（P0）
材料建档（品类/规格/单位/阈值/单价）、入库、出库（可关联订单，库存不足拒绝）、低库存预警视图、出入库流水、库存由数据库触发器随流水自动维护。

### FR5 成本利润核算（P0）
订单登记耗用材料（单价快照、自动扣库存、材料成本自动汇总=Σ用量×单价）、录入工时成本；利润 = 数量×单价 − 材料成本 − 工时成本。

### FR6 客户管理（P1）
客户建档（手机号列表脱敏展示）、编辑、客户详情含订单历史。

### FR7 客户角色（P1）
我的订单列表/详情、在线提交定制需求（自动分类并归属创作者待确认）、无权推进订单状态。

### FR8 排期与提醒（P1）
按月排期日历数据（未完成订单按预估完成日期）、工期提醒接口。

### FR9 管理员（P0/P1）
用户增删改（角色分配、启用禁用、重置密码）、产品分类与材料品类维护、经营总览、公告发布（全员可见，P2 简化）。

### FR10 财务查看者（P0）
收支总览、利润趋势（月/季）、客户复购与价值分层、材料消耗分析；全部只读，不可写业务数据。

### FR11 经营数据分析（P0，创新点二）
利润趋势报表（月/季收入-成本-利润）、客户复购率与客单价、客户价值分层（≥8000 高/≥2000 中/其余普通）、材料消耗量与消耗成本。Java 报表接口与 Python 分析模块口径一致（仅统计已完成或"带实际完成日期的归档"订单）。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 基础增删改查响应 ≤1-2 秒（本地 MySQL） |
| 安全 | 角色越权拦截（HTTP 403）；客户/成本敏感字段脱敏；账号密码 BCrypt 加密存储；无效 token 401 |
| 易用性 | 单 APP 多角色、核心入口突出、蓝白简洁界面（借鉴 vLLM-HUST 官网设计语言） |
| 数据一致性 | 库存流水与库存量由触发器单点维护；订单状态流转集中校验；经营统计口径统一 |

## 5. 业务主流程（P0 闭环）
创作者建单/客户提交定制 → 智能分类(类型+工期+预估完成日期) → 订单入库(待确认) → 创作者推进状态机(制作中→待发货→已完成) → 完成自动写实际完成日期 → 统计口径自动纳入经营报表；耗料登记联动库存扣减与材料成本汇总。
