## 3. E2E 场景覆盖（116 项断言按场景）
1. 登录与 RBAC：四角色登录、无效 token 401、客户/财务越权建单 403。
1b. 公开自助注册：注册成功且仅客户角色、重复用户名 400、弱密码 400、新账号可登录、越权建单仍 403、创作者可见新客户档案。
2. 智能分类：定制→CUSTOM(7天)、现货→READY(2天)、批量60件→BATCH(15天)、未命中→GENERAL+warn。
3. 状态机：待确认→制作中→待发货→已完成 全链；非法流转(已完成→待确认)400；审计日志≥4 条；完成自动写实际完成日期。
4. 库存与成本：耗料登记、库存不足 400、触发器扣减(120→118)、材料成本自动汇总(2×8=16)、利润公式、流水关联订单、入库+50、低库存列表。
5. 客户角色：本人订单可见、跨客户数据隔离 403、提交定制(CUSTOM)、定制单待确认、无权流转 403、创作者确认开工。
6. 排期/提醒：日历数据、3 天内提醒列表。
7. 客户管理：脱敏电话、新增/更新/详情含订单历史。
8. 管理员：用户列表脱敏、创建财务账号、BCrypt 登录、禁用→禁止登录、新增分类、发布公告、创作者可见公告。
9. 财务报表：收支总览、利润趋势(月)、复购率/价值分层、材料消耗；客户访问管理接口 403；财务不可写订单 403。
10. 收尾闭环：定制单完成、已完成归档、取消+归档(不计入收入)。

## 4. 缺陷清单（开发过程发现并修复，真实记录）
| # | 缺陷 | 发现途径 | 修复 |
|---|---|---|---|
| 1 | 已超期未完成订单不进提醒 | Python 单测 | 提醒窗口含超期(截止≤今天+3) |
| 2 | 分类脚本多行 JSON 致 Java 解析失败(500) | E2E 首跑 | 客户端整段读取整体解析+兜底最后行 |
| 3 | OrderClassifierClient lastJson 作用域编译错 | mvn compile | 提升到 try 外声明 |
| 4 | Map.get(key,默认值) API 误用编译错 | mvn compile | 改 getOrDefault |
| 5 | v_due_reminder 缺 creator_id(500) | E2E | 视图补列(数据隔离) |
| 6 | admin 总览查 v_order_profit 缺列(500) | E2E | 直接聚合 orders 表 |
| 7 | 取消后归档订单被计入收入 | E2E 数据核验 | 口径=COMPLETED 或(ARCHIVED 且完成日期非空)，三端统一 |
| 8 | 循环外键 DDL 顺序(建库失败) | 建库实测 | 建表后 ALTER 追加 |
| 9 | Windows mysql 客户端 GBK 读 UTF-8 建库失败 | 建库实测 | --default-character-set=utf8mb4 |
| 10 | 打包被运行中 jar 锁占用 | package | 先停服务再打包 |
| 11 | Qt 编译: 缺 QJsonArray include / 友元签名不匹配 | mingw 构建 | 补 include、修正 friend 声明 |
| 12 | Qt 运行: 无参实例未自动登录 | 演示冒烟 | 支持命令行传用户名自动登录 |
