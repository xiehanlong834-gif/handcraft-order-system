# 03 详细设计 —— 独立手作创作者订单管理系统

## 1. 订单状态机（核心规则，集中校验）
```
PENDING_CONFIRM ──→ IN_PRODUCTION ──→ PENDING_SHIPMENT ──→ COMPLETED ──→ ARCHIVED
      │                   │                   │
      └──── CANCELLED ←───┘                   └──(完成自动写 actual_complete_date)
                   │
                   └──────→ ARCHIVED
```
- 实现位置：`OrderStatus` 枚举静态转移表；`OrderService.changeStatus()` 统一校验，非法流转返回 400。
- 每次流转写入 `order_status_log`（from/to/操作人/备注），构成审计链。
- 统计口径：仅 `COMPLETED` 或 `ARCHIVED 且 actual_complete_date 非空` 计入经营报表（取消单不计收入）。

## 2. 智能订单分类规则（创新点一，order_classifier.py）
| 优先级 | 命中关键词 | 类型 | 预估工期 |
|---|---|---|---|
| 1 | 定制/专属/个性化/按需 | CUSTOM | 7 天 |
| 2 | 现货/现款/成品 | READY | 2 天 |
| 3 | 批量/团购/多件 | BATCH | 3 + ceil(数量/5) 天 |
| 兜底 | 未命中 | GENERAL | 3 天(创作者可手动调整) |
- Java 建单时经 `ProcessBuilder` 调 Python 脚本，解析 stdout 全量 JSON（含预估完成日期）。
- 兜底单响应带 `warn` 提示。批量工期示例：60 件 = 3+12=15 天。
- 提醒规则：预估完成日 − 今天 ≤ 3 天（含已超期）且未完结 → 进入提醒（视图 v_due_reminder 同步口径）。

## 3. 成本核算设计
- 材料成本：`order_material` 记录耗用 `quantity_used × unit_cost`（单价快照），插入时校验库存充足并写 `stock_movement(OUT, 关联 order_id)`，由触发器扣 `material.stock_qty`；随后回写 `orders.material_cost = Σ(用量×快照单价)`。
- 工时成本：创作者录入 `orders.labor_cost`。
- 利润 = `quantity × unit_price − material_cost − labor_cost`（列表/详情即时计算）。

## 4. 关键类职责（java-backend）
| 类 | 职责 |
|---|---|
| AuthInterceptor/TokenStore/AuthContext | Bearer token 解析、会话 24h、线程级用户上下文 |
| OrderService | 建单(调分类器)、列表/详情、状态机流转+审计、耗料/工时成本、提醒/排期 |
| MaterialService | 材料 CRUD、出入库(流水驱动)、低库存、流水查询 |
| CustomerService | 客户 CRUD、脱敏、订单历史 |
| AdminController | 用户管理(BCrypt)、分类、公告、经营总览 |
| ReportController | 报表(SQL 聚合，口径同 Python) |
| OrderClassifierClient | 进程调用 Python 并解析 JSON |
| GlobalExceptionHandler | 统一错误体 {code,message} |

## 5. 客户端设计（qt-app/desktop-demo，Qt 6.8）
- ApiClient：QNetworkAccessManager 封装 GET/POST/PATCH，统一 Bearer 与 JSON 解析。
- MainWindow：登录后按角色构建导航页；左侧导航+堆栈布局；QSS 蓝白主题（#f7fbff 画布 / #ffffff 卡片 / #1d4ed8 主蓝，借鉴 vLLM-HUST 官网设计语言）。
- 页面：Creator[订单(提醒横幅+状态操作)/库存/客户]、Customer[我的订单+定制表单]、Admin[总览+用户+公告]、Finance[收支+趋势+复购+材料消耗]。
- 支持命令行自动登录（`handcraft_client.exe [username] [password]`）便于演示与截图。

## 6. 安全设计
- 密码 BCrypt（cost=10）存储，登录仅返回 token（永不明文回传）。
- 接口按角色放行；订单数据行级隔离（creator_id / customer_id）；越权一律 403。
- 敏感字段脱敏：客户列表与用户列表电话 `138****0000`；财务只读报表不暴露客户联系方式细节。
- token 无效/过期 401；禁用账号即时失效（登录即校验 status）。

## 7. 关键异常与边界
库存不足拒绝出库；数量≤0 拒绝；单价为负拒绝；重复用户名拒绝；非法状态流转 400；非归属订单 403/404；分类未命中回退 GENERAL 并 warn；订单完成仅能由 PENDING_SHIPMENT 转入。
