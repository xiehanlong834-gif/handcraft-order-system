# 02 概要设计 —— 独立手作创作者订单管理系统

## 1. 总体架构

```
┌─ Qt C++ 桌面/移动客户端 (qt-app/) ────────────────┐ 界面交互、按角色渲染导航
│  Creator / Customer / Admin / Finance 四类登录      │
└────────────────────┬──────────────────────────────┘
                     │ HTTP + JSON (REST, Bearer Token)
┌────────────────────▼──────────────────────────────┐
│ Java 业务接口层 (java-backend/, Spring Boot 3.2.5)  │
│  ├ 认证鉴权: 登录/Token/RBAC/数据行级隔离            │
│  ├ 订单: 状态机流转/审计日志/成本核算                │
│  ├ 库存/客户/排期/提醒                              │
│  ├ 管理员: 用户/基础数据/公告/总览                   │
│  └ 报表: 利润趋势/复购/材料消耗                      │
│          │ 进程调用(ProcessBuilder)                 │
│          ▼                                          │
│  python/order_classifier.py  智能分类(创新点一)      │
│  python/analytics.py         数据分析(创新点二)      │
└───────────────┬───────────────────────────────────┘
                │ JDBC
        ┌───────▼────────┐
        │ MySQL 8.0       │ 11表 + 3视图 + 1触发器 + 外键/三范式
        └────────────────┘
```

> 设计决策：Python 以本地脚本形式被 Java 进程调用（不部署独立服务，避免多语言部署复杂度）；报表同时提供 Java SQL 实现与 Python 直连 MySQL 实现，口径一致可交叉验证。

## 2. 技术选型
| 层 | 技术 | 说明 |
|---|---|---|
| 客户端 | Qt 6.8 (C++17, Widgets + Network) | 桌面演示可运行；同源可迁移 Android |
| 后端 | Java 17 + Spring Boot 3.2.5 | Web/Jdbc 起步依赖 + spring-security-crypto(仅 BCrypt) |
| 智能分类 | Python 3.10+ 标准库 | 关键词规则引擎，零第三方依赖 |
| 数据分析 | Python + sqlite3/pymysql | SQLite 演示 / MySQL 生产双模式 |
| 数据库 | MySQL 8.0 | utf8mb4 / InnoDB / 三范式 + 审计日志表 |
| 测试 | 自研 E2E 脚本(scripts/e2e_api_test.py) | 四角色 116 断言全自动 |

## 3. 模块划分
- common：ApiException/统一异常、Token 会话、AuthContext(线程级)、AuthInterceptor、Role 枚举
- auth：登录/登出/当前用户
- order：订单服务+控制器（状态机、成本、提醒、排期、客户定制）
- inventory：材料库存（流水驱动触发器）
- customer：客户档案管理
- admin：用户/分类/公告/经营总览
- report：财务只读报表（finance/admin）
- classifier：Python 进程调用器

## 4. 接口协议约定
- Base URL: http://host:8080/api；请求/响应均为 JSON（UTF-8）
- 鉴权头: `Authorization: Bearer <token>`；token 24h 有效（内存会话，可替换 JWT）
- 错误响应: `{code, message}`，HTTP 语义（400/401/403/404/500）
- 时间格式 ISO-8601；金额 decimal；列表按创建时间倒序

## 5. REST API 清单（与实现一致）
| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| POST | /auth/login | 公开 | 登录 → {token,user} |
| POST | /auth/register | 公开 | 自助注册(仅客户角色, 自动建档归属创作者) |
| POST | /auth/logout · GET /auth/me | 登录 | 会话管理 |
| GET | /orders | creator/customer | 订单列表(状态/关键词) |
| GET | /orders/{id} | 归属可见 | 详情+审计日志+耗料 |
| POST | /orders | creator | 建单(自动分类) |
| PATCH | /orders/{id}/status | creator | 状态机流转 |
| POST | /orders/{id}/archive · /cancel | creator | 归档/取消 |
| POST | /orders/{id}/materials | creator | 登记耗料(扣库存) |
| POST | /orders/{id}/labor-cost | creator | 录入工时 |
| GET | /orders/due-reminders · /schedule | creator | 提醒/排期 |
| GET/POST | /customers(/{id}) | creator | 客户管理 |
| GET/POST | /materials · POST /{id}/in|out · GET /low-stock · /{id}/movements | creator | 库存 |
| GET/POST | /admin/users(/{id}) | admin | 用户管理 |
| GET/POST | /admin/product-categories · /material-categories | admin(+GET creator) | 基础数据 |
| GET/POST | /admin/announcements | 全员GET/admin POST | 公告 |
| GET | /admin/overview | admin/finance | 经营总览 |
| GET | /reports/summary·profit-trend·repurchase·materials | finance/admin | 经营报表 |
| GET | /my/orders · POST /my/custom-requests | customer | 客户功能 |

## 6. 部署拓扑（本仓库实测环境）
MySQL 8.0.42(localhost:3306, 库 handcraft_order) ← Java(8080) ← Qt 客户端/测试脚本；Python 脚本随后端本地调用。
