# qt-app —— 移动端 APP（Qt C++）

> ⚠️ **状态：结构规划**。本仓库开发机无 Qt / Android SDK，无法在此构建。本目录为 Qt 客户端开发的模块划分与页面规划，开发时在 Qt Creator 中新建工程（建议 QML + Widgets 混合或纯 QML，按团队熟悉度取舍）。

## 定位（对应规划文档"APP 客户端"）

负责全部界面交互与本地页面逻辑；通过 HTTP + JSON 与 java-backend (REST API, 端口 8080) 通信。**单 APP 多角色**：登录后按角色加载不同页面栈与菜单，界面层不做数据权限判断（权限在服务端拦截，前端只做隐藏）。

## 页面规划（按角色）

```
启动页(Logo) → 登录页(角色自动识别, 服务端返回角色后跳转)
├─ 创作者工作台
│   ├─ 订单页(P0): 列表(按状态筛选:待确认/制作中/待发货/已完成)
│   │   ├─ 新建订单(手填 → 调 /api/orders, 后端自动智能分类+工期)
│   │   ├─ 订单详情(进度更新/备注/删除归档)
│   │   └─ 成本录入(材料成本+工时成本, 显示自动利润)
│   ├─ 库存页(P0): 材料列表/入库/出库(关联订单)/低库存红色预警
│   ├─ 排期日历页(P1): 月视图, 订单工期标注, 3天内到期高亮
│   └─ 客户页(P1): 客户列表/详情/订单历史
├─ 客户页: 我的订单列表(进度实时可见) / 订单详情 / 提交定制需求(表单)
├─ 管理员页: 用户管理 / 基础数据配置(产品分类/材料品类) / 经营报表查看 / 公告(简化)
└─ 财务查看者页: 收支总览 / 利润趋势图 / 成本明细 / 周期报表导出(P2)
```

## 网络层约定

- Base URL: `http://<后端IP>:8080`（模拟器用 10.0.2.2）
- 统一 JSON；登录后携带 token 请求头
- 图表建议用 Qt Charts；网络用 QNetworkAccessManager

## 关键 UI 交互（对应 P0 演示链路）

1. 创作者点"新建订单" → 填产品描述/数量 → 提交后立刻看到系统自动标出的订单类型与预估完成日期（展示创新点一）
2. 状态流转按钮按状态机逐级点亮
3. 完成订单 → 库存扣减提示 + 成本利润结算展示
4. 低库存/临期订单在首页做横幅提醒
